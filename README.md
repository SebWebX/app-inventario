# App de Inventario

Sistema de gestión de inventario del lado del cliente construido con JavaScript vanilla. Soporta operaciones CRUD completas, cálculos automáticos de stock y persistencia de datos con LocalStorage — sin backend requerido.

**[Demo en vivo](https://sebwebx.github.io/app-inventario/)** &nbsp;·&nbsp; **[Portafolio](https://sebwebx.github.io/mi-portafolio/)** &nbsp;·&nbsp; **[LinkedIn](https://www.linkedin.com/in/sebaswebdevx/)**

---

## Funcionalidades

- Alta de productos con nombre, SKU, categoría, cantidad, stock mínimo y precio unitario
- Renderizado en tiempo real de la lista de productos mediante manipulación del DOM
- Cálculos automáticos: total por producto (cantidad × precio) y total general del inventario
- Eliminación de productos del inventario
- Persistencia con LocalStorage — los datos sobreviven recargas y cierres de pestaña
- Diseño completamente responsivo (móvil y escritorio)

## Cómo usar el proyecto

**Opción 1 — Abrir directo:**

Descarga o clona el repositorio y abre `index.html` en tu navegador. No requiere proceso de build.

**Opción 2 — Clonar con Git:**

```bash
git clone https://github.com/SebWebX/app-inventario.git
cd app-inventario
```

Luego abre `index.html` en tu navegador.
